# NewsPulse-24

## 🎬 @yousuf_lab — Promo Video Package

The `video-promo/` folder contains the production package for the 75-second
"Stop Using Boring Intros." promo (cinematic / futuristic / high-energy):

- **`video-promo/index.html`** — a fully animated, interactive **animatic** of the
  whole video: all 6 scenes (Hook → Intro → Showcase → Process → Why Me → CTA)
  with glitch transitions, text overlays, synthesized sound design (whooshes,
  bass drop, 128 BPM electronic beat, checkmark dings, final click) and a
  scrubbable timeline. Just open it in a browser and press ▶.
- **`video-promo/storyboard.md`** — the shot-by-shot storyboard with copy-paste
  AI video prompts (Runway / Kling / Veo / Sora), overlay list, audio plan and
  export checklist.

Quick preview:

```bash
cd video-promo && python3 -m http.server 3000 --bind 0.0.0.0
# → http://localhost:3000
```
